## Состояние продукта

**Теперь надёжно**, проверено тестами:
- клиент платит по публичному каталогу и не платит за неудачные и брошенные запросы;
- ответы провайдеров не склеиваются, обрыв посреди стрима виден клиенту как ошибка;
- проверка баланса не зависит от длины истории клиента.

**Остаётся риском** (по убыванию):

| Риск | Почему важно | Где |
|---|---|---|
| Деньги во `Float`, округление `Math.round` | У gpt-4o-mini 14,75% запросов расходятся с точным десятичным расчётом на 0,0001 ₽ — комплаенс Нова Банка это найдёт | `pricing.ts`, `schema.prisma` |
| Нет идемпотентности на сервере | Проба форка: 3 запроса с одним `Idempotency-Key` — 3 списания и 3 разных `requestId`. Ущерб от повторов SDK сейчас закрыт только остановкой генерации и нулевой ценой ошибок | `chat.ts`, `app.ts` |
| SDK 1.4.2 у клиентов | Игнорирует событие `error` и обрыв без `[DONE]`: клиенты на старом SDK по-прежнему не увидят ошибку | `sdk/client.ts` |
| Гонка баланса | Проверка до запроса, списание после: параллельные запросы уходят за `creditLimit` | `chat.ts` |

| Админка | Один общий токен (по умолчанию `dev-admin`, зашит в бандл кабинета), тот же порт, нет разграничения по организациям; ключи в БД открытым текстом; ключ принимается без `Bearer` | `admin.ts`, `auth.ts`, `web/src/api.ts` |

## Ревью своих изменений

Что проверил в диффе и что поправил перед сдачей:
- **Убраны исторические комментарии** («раньше здесь было…») из кода и тестов — история теперь в
  сообщениях коммитов.
- **Убрана обёртка `priceFor`**: после удаления `LEGACY_PRICES` она ничего не делала.
- **`clientGone`** вешается до авторизации, но срабатывает только если ответ не завершён — на
  401/400/402 не влияет.
- **Неудачный запрос** пишет оценку входных токенов при сумме 0 и `status=error`. Сверка «токены ×
  каталог» должна пропускать строки `error` — так и делает `refunds.ts`.
- **Обычный ответ при уходе клиента** отправляет 502 в уже закрытое соединение. Безвредно, но в
  проде даст строку в логе; можно не отвечать, если `signal.aborted`.
- **Резерв** по-прежнему списывается по полной цене модели — осознанно не трогал, это решение
  по продукту (см. риски).

## Что не успел и что дальше

**Срочно, до пилота Нова Банка:** деньги целыми числами (стоимость в 1e-5 ₽) или Decimal,
согласовать с банком правило округления; запрашивать `stream_options.include_usage`.

**На этой неделе:**
- **Лимиты на ключ для Альфы** (условие продления, срок 1 ноября), вместе с гонкой баланса.
- **Идемпотентность на сервере** (`Idempotency-Key` → один `chatcmpl-…` на все попытки).
- **SDK 1.4.3** — 10 правок от форка, подтверждённых пробами: таймаут на первый байт и на простой
  вместо общего, не повторять после начала стрима, требовать `[DONE]`, разбирать событие
  `{"error":…}`, повторы только по 429/5xx с паузой, один `Idempotency-Key`, `signal` от
  вызывающего кода, разбор HTTP-ошибок, отдавать `usage.total_cost`, версия в константе. Пока
  нет серверной идемпотентности, повторы по таймауту лучше выключить.
- **CSV-выгрузка** по ключам, дням и моделям (Пиксель, бухгалтерия Альфы).
- **Безопасность админки** до API ключей для ИнтегроСофт.
- **Мониторинг:** доля 499/502, время до первого токена, доля фолбэков, расхождение с каталогом.

**Отложено:** `/v1/messages` для Нова Банка (после гарантии по ценам), MCP-сервер (вернуться к
фаундеру с предложением).

**Выкладка:** перед деплоем `npx prisma db push` (новые индексы).

## Как работали

Основная сессия вела план, исправления и коммиты. Параллельно два форка в той же папке, без
права менять файлы проекта:
- **первый** — разбор кода и логов (13 находок, сводная страница), `scripts/refunds.ts`, список
  правок SDK 1.4.3 по пробам на локальном сервере, проба идемпотентности, замеры баланса;
- **второй (QA)** — независимая сверка всех чисел на Python/Decimal и SQL, мутационная проверка
  тестов.
