## Сегодня

1. **Списание строго по каталогу.** Убрать `LEGACY_PRICES` из расчёта.
   Тест: стоимость = цена из `/v1/models` × токены для каждой модели.
   Расхождение с публичным каталогом — баг при любом ответе фаундера. Если договорные цены у
   кого-то реальны, их надо вернуть как цены организации, а не глобально.
2. **Не списывать за неудачные запросы по максимуму.** При ошибке списывать 0 или фактически
   полученное от провайдера; статус `error` с нулевой суммой. Тест на фейковом провайдере.
3. **Обрыв клиента = остановка генерации.** Пробрасывать `AbortSignal` от закрытия соединения в
   провайдер; если клиент ушёл до конца — не списывать (или списывать только отданное, обсудить).
4. **Без склейки ответов.** Фолбэк на резерв — только если клиенту ещё ничего не отправлено;
   если стрим уже начался — отдать клиенту SSE-событие ошибки, а не молча `end()`.
5. **Быстрый баланс.** Агрегат в БД (`SUM` + индекс по `orgId`) вместо выгрузки всех строк;
   дальше — хранимый баланс. Проверка: balanceMs на данных Альфы до/после.
6. **Посчитать возвраты.** Скрипт по таблице `Usage`: переплата по legacy-ценам и списания
   со статусом `error` по всем клиентам за весь период; отдельно — инцидент 21.10 Альфы.
   Запускать на снимке прод-базы: `npm run setup` после исправления засевает историю уже по
   каталогу, и переплата в свежей базе исчезает.
7. Каждый пункт — с тестом в `test/`, в конце `npm test` и `npm run typecheck`.

## На этой неделе

- **Лимиты расходов на ключ для Альфы** (условие продления, срок 1 ноября): поле лимита на
  `ApiKey`, проверка перед запросом, 402 при превышении, настройка в кабинете.
- **SDK 1.4.3**: таймаут на первый байт, а не на весь ответ, больше дефолт; не ретраить после
  начала стрима; `Idempotency-Key`, чтобы ретрай не создавал новое списание.
- **Идемпотентность на сервере**: принимать `Idempotency-Key` и отвечать на повтор тем же
  результатом без нового списания. Без неё ключ в SDK ничего не даёт.
- **CSV-выгрузка расходов** (Пиксель): по ключам, дням и моделям; её же отдать бухгалтерии Альфы.
- **API ключей для реселлера** (ИнтегроСофт): создать/отозвать ключ, расход по ключу.
  Ложится на ту же модель, что и лимиты.
- **Гонка баланса**: баланс проверяется до запроса, списание после — параллельные запросы уходят
  за `creditLimit`; с лимитами на ключ станет заметно. Резервировать сумму до запроса.
- **Безопасность админки** (до API ключей для ИнтегроСофт): один общий токен (`dev-admin` по
  умолчанию, зашит в бандл кабинета), нет разграничения по организациям; ключи в БД открытым текстом.
- **Деньги во `Float`** — перейти на целые (стоимость в 1e-5 ₽) или Decimal. Уже сейчас
  `calcCost` округляет до 4 знаков на float: у gpt-4o-mini около 15% запросов расходятся с
  точным десятичным расчётом на 0.0001 ₽ — комплаенс Нова Банка это найдёт. Срочно до пилота.
- **Мониторинг**: алерты на долю 499/502, время до первого токена, долю фолбэков на резерв,
  расхождение списаний с каталогом.
